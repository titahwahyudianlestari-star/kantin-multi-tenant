\# Kantin Multi-Tenant



Aplikasi praktikum Kantin Multi-Tenant menggunakan Laravel 13.



\## Requirements



\- PHP 8.4 atau lebih baru

\- Composer

\- Node.js dan npm

\- MySQL

\- Redis

\- Laravel 13

\- Livewire 4

\- Laravel Reverb



\## Setup



Clone atau buka project, kemudian jalankan:



```bash

composer install

npm install
